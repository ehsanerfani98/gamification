# 🚀 راهنمای اجرای بتای ۵ فروشگاه

> **دامنه:** اجرای عملیاتی بتا روی سرور تولیدی — پس از Sprint 8
> **پیش‌نیاز کد:** سندباکس پیامک/پرداخت + بخش «تنظیمات سایت» پنل (کاملاً آماده است)
> **قاعده طلایی بتا:** هیچ کلید واقعی IPPanel/ZarinPal در دوره بتا لازم نیست — همه‌چیز با سندباکس اجرا می‌شود.

---

## گام ۰ — استقرار روی سرور (پیش‌نیاز)

راهنمای کامل در `README.md` (بخش «راهنمای استقرار») است؛ خلاصه چک‌لیست:

```bash
git clone https://github.com/ehsanerfani98/gamification.git && cd gamification
composer install --no-dev --optimize-autoloader
cp .env.example .env && php artisan key:generate --force
# در .env: APP_ENV=production ، APP_DEBUG=false ، APP_URL=https://دامنه-شما
touch database/database.sqlite
php artisan migrate --force
php artisan db:seed --force
npm ci && npm run build
php artisan config:cache && php artisan route:cache && php artisan view:cache
```

سپس Worker صف، Scheduler (cron هر دقیقه) و وب‌سرور را طبق README بالا بیاورید.
برای دموی داخلی پیش از ورود پایلوت‌ها: `php artisan demo:seed` → لینک `/c/demo-wheel`.

## گام ۱ — ارتقای مدیر سایت

1. با شماره شخصی یک‌بار وارد پنل (`/panel`) شوید (OTP در حالت بدون سندباکس در `storage/logs/laravel.log` می‌افتد؛ در محیط non-production در پاسخ API هم می‌آید).
2. روی سرور اجرا کنید:
   ```bash
   php artisan admin:promote 09xxxxxxxxx
   ```
3. از پنل خارج و دوباره وارد شوید (توکن جدید با ability «admin» صادر شود) — منوی «تنظیمات سایت» ظاهر می‌شود.

## گام ۲ — روشن‌کردن سندباکس‌ها از پنل

پنل → **تنظیمات سایت** (فقط Admin):

- **سندباکس پیامک** را روشن کنید → OTP مشتریان و فروشگاه‌داران واقعاً ارسال نمی‌شود؛
  کد در پاسخ API (`debug_code`) و در لاگ می‌آید.
- **سندباکس دروازه پرداخت** را روشن کنید → خرید اشتراک به‌جای ZarinPal به صفحه پرداخت
  آزمایشی داخلی می‌رود؛ دکمه «پرداخت موفق/ناموفق» همان مسیر callback → verify →
  فعال‌سازی اشتراک → فاکتور → Audit را اجرا می‌کند.

هر تغییر در Audit با `site.settings_updated` ثبت می‌شود. وضعیت زنده را همیشه می‌توانید ببینید:

```bash
php artisan beta:status
```

## گام ۳ — Onboarding هر فروشگاه پایلوت (۵ فروشگاه)

برای هر فروشگاه این مسیر را همراه فروشگاه‌دار طی کنید و تیک بزنید:

| # | گام | راهنما |
|---|-----|--------|
| ۱ | ورود با OTP (سندباکس) | فروشگاه‌دار شماره می‌دهد؛ کد از مدیر سایت می‌گیرد |
| ۲ | ساخت فروشگاه | نام فروشگاه → Plan رایگان خودکار فعال می‌شود |
| ۳ | ارتقای Plan (اختیاری) | از بخش اشتراک → Plan پایه/حرفه‌ای → پرداخت سندباکس («پرداخت موفق») |
| ۴ | ساخت کمپین | کتابخانه بازی → Wizard دو مرحله‌ای → پیکربندی بازی |
| ۵ | تعریف جایزه | ۹ نوع جایزه با موجودی (حداقل یک کوپن و یک امتیاز پیشنهاد می‌شود) |
| ۶ | انتشار و دریافت لینک | لینک عمومی `/c/{slug}` را در اینستاگرام/مرورگر باز کنید |
| ۷ | بازی واقعی مشتری | ورود مشتری با OTP سندباکس → بازی → جایزه → کیف جایزه‌ها |
| ۸ | ثبت استفاده کوپن | در پنل، کد کوپن مشتری را redeem کنید (حلقه ROI) |
| ۹ | بررسی گزارش | Analytics کمپین: قیف Enter→Play→Win→Redeem |

> اگر فروشگاه‌دار خواست قبل از کمپین واقعی، سیستم را ببیند: `php artisan demo:seed`
> و ارسال لینک `/c/demo-wheel` به او.

## گام ۴ — عملیات روزانه/هفتگی دوره بتا

- **Scheduler فعال باشد** (cron): بستن کمپین منقضی، انقضای Sessionها، تجمیع شبانه Analytics (۰۳:۰۰) و بکاپ (۰۴:۰۰) خودکار اجرا می‌شوند.
- **بکاپ:** فایل‌های `storage/app/backups` را گاه‌به‌گاه خارج از سرور کپی کنید (`php artisan database:backup`).
- **پایش:** هر روز `php artisan beta:status` — اگر پرداخت سندباکس غیرمنتظره‌ای دیدید، Audit (`audit_logs`) را بررسی کنید.
- **لاگ‌ها:** `storage/logs/laravel.log` — خطاهای صف پیامک (در سندباکس هیچ Job پیامکی dispatch نمی‌شود).

## گام ۵ — جمع‌آوری بازخورد

- برای هر فروشگاه پایلوت یک کپی از `docs/BETA_FEEDBACK_TEMPLATE.md` پر کنید (بهتر: خود فروشگاه‌دار پر کند).
- بازخوردها را در یک فایل مشترک (مثلاً `docs/beta-feedback/{store-name}.md`) یا Google Doc نگه دارید.
- اشکالات را اولویت‌بندی کنید: مسدودکننده جریان اصلی → قبل از پایان بتا؛ بهبودها → Backlog نسخه بعد.

## گام ۶ — پایان بتا: گذار به کلیدهای واقعی (بدون تغییر کد)

پس از جمع‌بندی بازخوردها و رفع اشکالات مسدودکننده:

1. در پنل → تنظیمات سایت: هر دو سندباکس را **خاموش** کنید.
2. در `.env` سرور:
   ```env
   SMS_CHANNEL=ippanel
   IPANEL_API_KEY=…            # کلید واقعی شما
   IPANEL_ORIGINATOR=…         # شماره خط پیامک
   PAYMENT_GATEWAY=zarinpal
   ZARINPAL_MERCHANT_ID=…      # Merchant ID واقعی شما
   ```
3. `php artisan config:clear && php artisan config:cache` و Restart Worker صف.
4. یک خرید واقعی کوچک انجام دهید و وریفای ZarinPal و رسید پیامک IPPanel را ببینید.
5. داده‌های آزمایشی بتا (در صورت نیاز) پاک شوند و دیتابیس بکاپ نهایی گرفته شود.
